# Python Validation Application

A menu-driven Python application that validates various user inputs using Regular Expressions (Regex). The project allows users to validate Phone Numbers, Usernames, Email Addresses, PAN Numbers, Vehicle Registration Numbers, Passport Numbers, Aadhaar Numbers, and Voter ID Numbers through an interactive console interface.

## Features

* Phone Number Validation
* Username Validation
* Email Address Validation
* PAN Card Validation
* Vehicle Registration Validation
* Passport Number Validation
* Aadhaar Number Validation
* Voter ID Validation
* Menu-Driven User Interface
* Exception Handling for Invalid Inputs

## Technologies Used

* Python
* Regular Expressions (re Module)
* Exception Handling

## Objective

The purpose of this project is to demonstrate the practical use of Regular Expressions in Python for validating different types of user information while improving input handling and program reliability through a menu-driven application.
